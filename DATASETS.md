# DATASETS.md

Reference for the two base HuggingFace datasets that everything else is built on.

---

## `thoughtworks/psychometric_personas`

Synthetic law-enforcement personas generated by GPT-4o (version `v12`), each with demographics, psychological traits, memoir, and a presenting problem. Used as the persona injection source for all HEXACO and SJT response runs.

| Config | Split | Rows | Description |
|---|---|---|---|
| `analysis` | train | 500 | Primary analysis set. 500 v12 personas used for the main HEXACO and SJT experiments. |
| `base` | train | 8500 | Full base generation pool (v12). Superset of `analysis`. |
| `default` | train | 8500 | Same as `base`. |
| `default` | restricted | 1504 | Restricted subset of default. |
| `expanded` | train | 3008 | Expanded subset. |
| `restricted` | train | 1504 | Restricted subset (e.g. demographic-filtered). |
| `annotated` | train | 55 | Hand-annotated personas used for qualitative validation. |
| `comparison_openai` | train | 100 | First 100 rows of `analysis` — the reference set for cross-generator comparison. Version `v12`. |
| `comparison_anthropic` | train | 100 | Claude Sonnet re-generations of the same 100 seeds as `comparison_openai`. Same UUIDs, different prose. Version `comparison_anthropic`. |
| `test_sample` | train | 30 | Small sample for quick smoke tests. |

**Key fields:** `uuid`, `persona_hash` (SHA-256), `persona_string` (full injectable text), `version`, `name`, `age`, `sex`, `location`, `ethnic_background`, `appearance`, `behavior`, `speech`, `memoir`, `presenting_problem`, and HEXACO seed attributes.

---

## `thoughtworks/psychometric_SJTs`

Raw bank of 4000 SJT items (full generation pool, before curation). Each item has 6 HEXACO-keyed answer options (`original_sjt`) and a corrected version (`corrected_sjt`) that was reviewed for trait bleed.

| Config | Split | Rows | Description |
|---|---|---|---|
| `default` | train | 4000 | Full uncurated SJT bank. |

**Key fields:** `hash_id`, `original_sjt` (dict of 6 trait options + question), `corrected_sjt` (trait-bleed-corrected options), `trait_bleed_evaluation`.

---

## `thoughtworks/psychometric_sjts_analysis`

Curated subsets of the SJT bank used for actual experiments. All items have scenario metadata and 1024-dim embeddings. `corrected_sjt` is what gets used in prompts.

| Config | Split | Rows | Description |
|---|---|---|---|
| `analysis` | train | 300 | Primary analysis set. 300 curated items used for the main 500-persona run. |
| `expanded` | train | 1000 | Larger curated set (superset of `analysis`). |
| `restricted` | train | 500 | Intermediate curated set. |
| `debug` | train | 20 | 20-item subset for quick iteration. |
| `annotated` | train | 30 | Hand-annotated items with inter-rater reliability scores. |
| `anthropic_claude` | train | 100 | 100 SJT items generated by Claude (Anthropic-authored scenarios). |
| `comparison_openai` | train | 100 | 100 items drawn from `analysis` for cross-generator comparison. |
| `comparison_anthropic` | train | 100 | Claude-regenerated versions of the same 100 scenarios as `comparison_openai`. Each row has a `source_hash_id` pointing to its `comparison_openai` counterpart. Direct hash overlap with `comparison_openai` is 0 (different text → different hash). |

**Key fields:** `hash_id`, `corrected_sjt` (dict: `question` + 6 trait options), `original_sjt`, `trait_bleed_evaluation`, `sjt_embedding` (1024-dim), `base_scenario`, `age`/`gender`/`race` (scenario placeholders), `ambiguity_level`, `threat_level`, `urgency_level`, `situation_type`, `ethical_considerations`, `template_no`.

```
                                         ├──▶  gemma_psychometrics_personas_responses/analysis_sjt
psychometric_sjts_analysis/analysis (300)──┘    500 personas × 300 SJTs × 5 iters = 750,000 rows
                                                 Model: google/gemma-3-4b-it  |  Run: 2026-03-11

psychometric_personas/comparison_openai (100) ──┐
                                                  ├──▶  (pending) comparison_openai_sjt
psychometric_sjts_analysis/analysis (300) ────────┘

psychometric_personas/comparison_anthropic (100) ──┐
                                                     ├──▶  (pending) comparison_anthropic_sjt
psychometric_sjts_analysis/analysis (300) ──────────┘
```
