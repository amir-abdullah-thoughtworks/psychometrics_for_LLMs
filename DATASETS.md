# DATASETS.md

Reference for the two base HuggingFace datasets that everything else is built on. All response-generation runs draw personas and SJT items from these.

> **Naming convention:** `cmp_openai` and `gpt` are used interchangeably throughout (OpenAI/GPT-4o-generated). `cmp_anthropic` and `claude` are used interchangeably (Claude-generated).

---

## `thoughtworks/psychometric_personas`

Synthetic law-enforcement personas generated by GPT-4o (`version=v12`), each with demographics, psychological traits, memoir, and a presenting problem. `comparison_anthropic` is the only config not generated by OpenAI — it is a Claude Sonnet re-generation of the same seeds.

**Key fields:** `uuid`, `persona_hash` (SHA-256), `persona_string`, `version`, `name`, `age`, `sex`, `location`, `ethnic_background`, `appearance`, `behavior`, `speech`, `memoir`, `presenting_problem`, HEXACO seed attributes.

| Config | Split | Rows | Description |
|---|---|---|---|
| `base` | train | 8500 | Full generation pool. All other configs are drawn from this. |
| `expanded` | train | 3008 | Subset of `base`. |
| `restricted` | train | 1504 | Subset of `base` and `expanded`. |
| `analysis` | train | 500 | Primary analysis set. Subset of `base`. Used for the main HEXACO and SJT experiments. |
| `annotated` | train | 55 | Hand-annotated subset of `base` used for qualitative validation. |
| `comparison_openai` | train | 100 | First 100 rows of `analysis`. The reference set for cross-generator comparison. |
| `comparison_anthropic` | train | 100 | Claude Sonnet re-generations of the same 100 seeds as `comparison_openai`. Same UUIDs and seed fields; all prose fields differ. |
| `test_sample` | train | 30 | Subset of `comparison_openai` (and therefore `analysis`) used for smoke tests. |

### Subset hierarchy

```
base (8500)
├── expanded (3008)
│   └── restricted (1504)
│       └── [partial overlap with analysis: 88]
├── analysis (500)  ← main experiment set
│   ├── comparison_openai (100)  ← same UUIDs, OpenAI prose
│   │   └── test_sample (30)
│   └── comparison_anthropic (100)  ← same UUIDs, Claude prose
│       └── test_sample (30)
└── annotated (55)  [5 overlap with analysis]
```

`comparison_openai` and `comparison_anthropic` share the same 100 UUIDs and seed attributes — they are parallel columns generated by different models from identical inputs.

## `thoughtworks/psychometric_SJTs`

Raw bank of 4000 SJT items (full generation pool, before curation). Each item has 6 HEXACO-keyed answer options (`original_sjt`) and a corrected version (`corrected_sjt`) reviewed for trait bleed.

| Config | Split | Rows | Description |
|---|---|---|---|
| `default` | train | 4000 | Full uncurated bank. |

**Key fields:** `hash_id`, `original_sjt` (dict: `question` + 6 trait options), `corrected_sjt`, `trait_bleed_evaluation`.

---

## `thoughtworks/psychometric_sjts_analysis`

Curated subsets drawn from `psychometric_SJTs`. All items include scenario metadata and 1024-dim embeddings. Prompts use `corrected_sjt` (trait-bleed-corrected) options.

**Key fields:** `hash_id`, `corrected_sjt` (dict: `question` + 6 HEXACO trait options), `original_sjt`, `trait_bleed_evaluation`, `sjt_embedding` (1024-dim float array), `base_scenario`, `age`/`gender`/`race` (scenario placeholders), `ambiguity_level`, `threat_level`, `urgency_level`, `situation_type`, `ethical_considerations`, `template_no`.

| Config | Split | Rows | Description |
|---|---|---|---|
| `expanded` | train | 1000 | Largest curated subset. All other configs except `anthropic_claude` are subsets of this. |
| `restricted` | train | 500 | Subset of `expanded`. |
| `analysis` | train | 300 | Primary experiment set. Subset of `expanded`. Used for the main 500-persona run. |
| `debug` | train | 20 | Subset of `restricted` (and `expanded`). For quick iteration. |
| `annotated` | train | 30 | Hand-annotated items with inter-rater reliability scores. Not a hash-subset of the others. |
| `comparison_openai` | train | 100 | Subset of `analysis` (and `expanded`). Same 100 items drawn for cross-generator SJT comparison. |
| `comparison_anthropic` | train | 100 | Claude-generated SJTs from the same handmade template × seed combinations used to produce `comparison_openai`. Independently generated (not a rewrite of OpenAI text). Each row has `source_hash_id` pointing to its paired `comparison_openai` item (same template+seed, different model). |

### Subset hierarchy

```
psychometric_SJTs/default (4000)  ← raw pool
└── expanded (1000)  ← curated superset
    ├── restricted (500)
    │   ├── debug (20)
    │   └── [152 overlap with analysis]
    └── analysis (300)  ← main experiment set
        ├── debug (7 items also in debug)
        └── comparison_openai (100)  ← same hash_ids, OpenAI-authored
            └── comparison_anthropic (100)  ← Claude-generated from same template+seed, source_hash_id → comparison_openai

annotated (30)  ← hand-annotated, not a strict subset of any config
```

`comparison_openai` and `comparison_anthropic` cover the same 100 scenarios — one OpenAI-authored, one Claude-authored — making them a paired set for model comparison on identical scenario seeds.

### PersonaLLM personas

`personallm_persona_*` configs use a minimal persona format from the PersonaLLM paper: each persona is exactly 6 adjectives (one per HEXACO trait), expressing the high or low pole of that trait. The full 2^6 = 64 combinations are enumerated.

See [`llm_psychometrics/configs/persona_llm_hexaco_poles.yaml`](llm_psychometrics/configs/persona_llm_hexaco_poles.yaml) for the explicit high/low adjective mapping per trait, and [`llm_psychometrics/configs/persona_llm_paper_seeds.yaml`](llm_psychometrics/configs/persona_llm_paper_seeds.yaml) for the seed values used to generate all 64 combinations.

